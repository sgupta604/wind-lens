## Bug Summary

The dome wind visualization shows the opposite north-south wind direction compared to the AR view. A wind blowing SE in AR appears as NE in the dome. The east-west (u) component is correct; only the north-south (v) component is inverted.

**Root cause:** In `dome_particle.dart` line 121, `z += wind.v` should be `z -= wind.v`. The dome coordinate system has +z = South (confirmed by compass rose in `dome_painter.dart`), but the wind convention has +v = Northward. Positive v must decrease z (move toward -z = North), not increase it.

## Architecture Overview

No architectural changes. This is a sign correction in a single arithmetic expression.

```
DomeWindField.sample(x,y,z)         WindVector { u, v }
         |                                |
         v                                v
DomeParticle.tick():                 Convention:
  x += wind.u * scale * dt           u: +x = East     (correct)
  z += wind.v * scale * dt  <-- BUG  v: +z = South    (inverted)
  z -= wind.v * scale * dt  <-- FIX  v: -z = North    (correct)
```

## Test Strategy

Add to the existing `tick()` group in `dome_particle_test.dart`:

1. **Northward wind moves particle toward -z**: Create a wind field with u=0, v=+10. Tick a particle at the origin. Assert `p.z < 0` (moved toward North = -z) and `p.x` unchanged.
