## Data Model Changes

### AltitudeLevel Enum Expansion

**Before (3 values):**
```dart
enum AltitudeLevel { surface, midLevel, jetStream }
```

**After (6 values):**
```dart
enum AltitudeLevel { surface, midLevel, level700, level500, level300, jetStream }
```

**Order matters:** Values are ordered from lowest to highest altitude. This is used by the slider to map indices to levels.

### Property Values for All 6 Levels

| Level | Pressure | metersAGL | displayName | particleColor | speedMult | parallax | trailScale | streamlinePts |
|-------|----------|-----------|-------------|--------------|-----------|----------|------------|---------------|
| `surface` | 0 | 10 | "Surface" | 0xAAFFFFFF (white) | 1.0 | 1.0 | 1.0 | 12 |
| `midLevel` | 850 | 1500 | "850 hPa" | 0xAA00DDFF (cyan) | 1.5 | 0.6 | 0.7 | 18 |
| `level700` | 700 | 3000 | "700 hPa" | 0xAA00AAFF (blue) | 1.8 | 0.5 | 0.65 | 20 |
| `level500` | 500 | 5500 | "500 hPa" | 0xAA8855FF (violet) | 2.2 | 0.4 | 0.6 | 22 |
| `level300` | 300 | 9000 | "300 hPa" | 0xAABB33FF (magenta) | 2.7 | 0.35 | 0.55 | 24 |
| `jetStream` | 250 | 10500 | "250 hPa" | 0xAADD00FF (purple) | 3.0 | 0.3 | 0.5 | 25 |

**Notes:**
- `midLevel.displayName` changes from "Cloud Level" to "850 hPa"
- `jetStream.displayName` changes from "Jet Stream" to "250 hPa"
- Colors form a spectral gradient: white -> cyan -> blue -> violet -> magenta -> purple
- Speed multipliers increase roughly linearly from 1.0 to 3.0
- Trail scale and parallax decrease linearly (higher = further away = smaller/slower trails)

### Pressure Level to API Mapping

```dart
static int _altitudeToPressure(AltitudeLevel altitude) {
  return switch (altitude) {
    AltitudeLevel.surface  => 0,    // Surface collection (no z param)
    AltitudeLevel.midLevel => 850,  // GFS_isobaric z=850
    AltitudeLevel.level700 => 700,  // GFS_isobaric z=700
    AltitudeLevel.level500 => 500,  // GFS_isobaric z=500
    AltitudeLevel.level300 => 300,  // GFS_isobaric z=300
    AltitudeLevel.jetStream => 250, // GFS_isobaric z=250
  };
}
```

All 6 levels are supported by both Shyft and Folkweather APIs (verified in research).

## Implementation Notes

### Design Decisions

1. **Enum expansion over sealed class:** Research confirmed this is the safest approach. Dart exhaustive switch checking catches all incomplete cases at compile time. No Freezed/JSON serialization changes needed.

2. **Keep `midLevel` and `jetStream` enum value names:** Renaming would create a massive diff for cosmetic benefit. The `displayName` property changes from "Cloud Level"/"Jet Stream" to "850 hPa"/"250 hPa" for UI consistency.

3. **Snap-to-nearest, not truly continuous:** The slider feels continuous (smooth dragging) but snaps to the 6 discrete pressure levels where real data exists. The readout updates immediately to show the snapped value.

4. **No interpolation between pressure levels:** Wind data at intermediate altitudes would be meaningless (the atmosphere doesn't interpolate linearly between pressure levels). Snap-to-nearest is both simpler and more honest.

5. **Dome altitude label is static:** The dome fetches surface/850/700 (0-3000m). This is independent of the AltitudeLevel enum and does not need a selector. Just a label showing what range is displayed.

6. **Slider readout shows meters + pressure:** e.g., "1,500m / 850 hPa" or just "1,500m" depending on space. This gives users meaningful context about what altitude they're viewing.

### Patterns Used

- **Extension properties on enum:** Same pattern as existing code, just more cases
- **Riverpod Notifier:** `selectedAltitudeProvider` pattern unchanged
- **Glassmorphism styling:** BackdropFilter + semi-transparent Container + border
- **Haptic feedback:** `HapticFeedback.lightImpact()` on value change during drag
- **DM Mono font:** Consistent with home screen labels

### Trade-offs

- **Taller slider:** 6 stops at 48px each = 288px vs 3 stops at 56px = 168px. The slider is now ~70% taller. On a typical phone (812pt iPhone), this is about 35% of screen height, which is acceptable for a right-edge control.
- **Display name change:** Changing "Cloud Level" to "850 hPa" is technically more accurate but less intuitive for casual users. The meters display compensates (users can see "1,500m" next to "850 hPa").

### Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Shyft API missing some pressure levels | Low | Medium | Folkweather fallback covers all 6 levels |
| Slider too tall for small phones | Low | Low | 288px fits on all supported devices (minimum 667pt iPhone SE) |
| Codegen breaks after enum change | Low | High | Standard procedure: delete-conflicting-outputs |
| Missing switch cases compile error | High (intentional) | None | This is a benefit -- compiler catches every missed case |

## Non-Goals (NOT doing in this feature)

1. **Animated slider thumb:** The thumb snaps instantly. Animation between stops is a future polish item.
2. **Wind data interpolation between pressure levels:** Snap-to-nearest only.
3. **Dome altitude selector:** The dome gets a static label, not an interactive selector.
4. **Home particle painter multi-altitude visualization:** Home screen particles remain single-altitude.
5. **Changing dome fetch levels:** The dome continues fetching surface/850/700 as before.
6. **Renaming `midLevel`/`jetStream` enum value identifiers:** Only display names change.
