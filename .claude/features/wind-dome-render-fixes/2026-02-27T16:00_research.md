## Summary of Issues

### Issue 1 — Map and Dome Camera Not Synchronized
The dome has its own 3D camera (theta, phi, camDist). The map has its own camera (bearing, zoom). They don't talk to each other. Needs:
- **Fix A:** Bearing sync — `_mapController.rotate(-theta * 180 / pi)` when theta changes
- **Fix B:** Zoom behavior — camera zoom changes camDist, NOT dome size (DOME_R_RENDER is fixed)
- **Fix C:** Map zoom syncs with camera distance — `mapZoom = BASE_MAP_ZOOM - log(camDist / BASE_CAM_DIST) / log(2)`
- **Fix D:** Tilt effect — Transform widget wrapping FlutterMap with perspective + rotateX from phi

### Issue 2 — Zoom Transition: Dome ↔ Map View
Two natural zoom modes that flow into each other:
- Close zoom (camDist < DOME_THRESHOLD): dome prominent, 3D perspective
- Far zoom (camDist > MAP_THRESHOLD): dome shrinks, map takes over, phi→pi/2
- Smooth phi auto-adjust when crossing thresholds in ticker loop

### Issue 3 — Ground Disc Missing
Dark ground plane needed under dome. Draw filled dark ellipse BEFORE wireframe/particles.
64-segment projected circle at y=0, black 55% opacity fill + white 35% opacity stroke.

### Issue 4 — Dome Radius Presets Not Updating Visual
Tapping 500m/1km/2km updates domeSizeProvider but dome doesn't change visually.
DOME_R_RENDER read once at construction, needs to be reactive parameter.
Also: re-initialize particles on size change.

### Issue 5 — GPS Offset
Dome center offset from user position. Cache key coordinates (2-decimal rounding) being
used for positioning instead of raw GPS fix from stablePositionProvider.

### Issue 6 — Multi-Touch Gesture System (already mostly working, needs refinements)
Current system has 1-finger drag and 2-finger pinch. The fixes doc details the
complete gesture mapping and pointer tracking pattern.

### Issue 7 — Forecast Slider Not Updating Particle Simulation
Particles keep moving in old direction when slider changes. The ticker loop must
read currentDomeWindFieldProvider on every frame via ref.read(), not cache it.
Already correctly implemented in current code (ref.read on line 109 of wind_dome_screen.dart).
